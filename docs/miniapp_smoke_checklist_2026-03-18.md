# Miniapp Smoke Checklist（2026-03-18）

适用范围：`miniapp/` 的主流程快速验收。

目标：在 10-15 分钟内确认“小程序能浏览、能查询、能打开详情、报错不崩”。

## 0. 准备

- 微信开发者工具已打开 `miniapp/`
- 后端 API 可访问
- 如果要验证静默登录成功路径，准备好可用的 `WECHAT_APPID / WECHAT_SECRET`
- 如果只是本地浏览验收，可使用 `USE_MOCK_WECHAT=true`

## 1. 静默登录

### 1.1 成功路径

- 启动小程序
- 首页文案应显示“静默影子账户访问模式”
- 不应弹出阻塞式报错
- 继续点击“查询公告”或“查询调剂”，页面可正常进入

### 1.2 失败降级路径

- 让 `wx.login` 或 `/auth/silent-login` 失败
- 重新启动小程序
- 首页文案应显示“匿名访问模式”或“已自动降级为可浏览模式”
- 仍可继续进入公告/调剂查询页
- 不应因为登录失败卡死在首页

## 2. 公告查询链路

- 首页输入院校名与关键词
- 点击“查询公告”
- 结果页应能看到列表或稳定的空状态提示
- 点击任意一条结果
- 应能进入详情页

## 3. 调剂查询链路

- 首页输入院校名、关键词、专业、地区
- 点击“查询调剂”
- 结果页应能看到列表或稳定的空状态提示
- 点击任意一条结果
- 应能进入详情页

## 4. 详情页容错

- 使用完整字段数据进入详情页
- 标题、院校、时间、分类、来源应可展示
- 有 `summary` 时展示摘要卡片
- 没有 `summary` 但有 `body` 时展示正文摘要卡片
- 缺少 `major / region / source_url` 时页面不应崩溃
- 点击“复制链接”时：
  - 有链接则提示复制成功
  - 无链接则提示“暂无原文链接”

## 5. 状态页一致性

- 主动制造一次查询错误或详情参数错误
- 进入状态页后，标题和文案应可读
- 如果存在页面栈，应优先显示“返回上一页”
- 任意情况下都应可“返回首页”

## 6. 判定标准

- `wx.login` 成功或失败都不阻塞浏览
- 搜索 -> 列表 -> 详情链路可走通
- 缺字段不会导致详情页崩溃
- 错误页始终可返回
- 空结果和网络失败都有稳定文案
